# 品牌要素

> 来源：Pangea Design「标识」规范（飞书 wiki，含《海信集团 VI 手册》标准文件）。本文件只收录有明确来源的规则；尚未定义的品牌要素列在文末，**不要自行补充**。

## 一、Logo

### 规则（硬约束）

1. **所有系统界面中出现的品牌标识，统一使用 `Hisense` 品牌标准版本标识。**
2. **颜色只有两种**：
   - **海信绿**：用在浅色底上。色值 `#00AAA6`，与主题主色 `--primary-6` 完全一致。
   - **反白**：用在深色底、品牌色底或图片上。
3. **不可变形**。尺寸不合适时只能等比缩放，或裁剪 / 扩展 Logo 周围的留白区域；不能单独拉伸宽或高。标准文件宽高比约 **3.81 : 1**（2219.7 × 582）。实现时只设宽或只设高，另一边自动（`height: auto` / `width: auto`），或使用 `object-fit: contain`。
4. **除联合项目外（非甲乙方关系），界面中不允许出现海信以外的品牌标识。**
5. 不改字形、不加描边 / 阴影 / 渐变、不换其它颜色。

### 正误示例

| | 示例 |
|---|---|
| ✅ 正确 | 浅色底上的海信绿 Logo |
| ✅ 正确 | 灰色 / 深色底上的反白 Logo |
| ❌ 错误 | 被纵向拉伸、比例失调的 Logo |

### 标准文件（本 skill 已内置，`assets/brand/`）

| 文件 | 用途 |
|---|---|
| `hisense-logo.svg` | **首选**。海信绿矢量标识（官方原始文件） |
| `hisense-logo-white.svg` | 反白矢量标识。由官方 SVG 只把填充色改为 `#FFFFFF` 得到，路径未改 |
| `hisense-logo.png` | 海信绿位图（228 × 61），仅在无法使用 SVG 时用 |
| `hisense-logo-white.png` | 反白位图（4625 × 1213，官方原始文件），按需缩小使用 |
| `favicon.ico` | 默认浏览器页签图标（128 × 128） |

把需要的文件复制到用户项目的静态资源目录后引用，不要用文字或自绘图形模拟 Logo。

### 头部导航中的 Logo（推荐）

头部高 48px 时，Logo 宽 108px、垂直居中，超出头部高度的部分隐藏；Logo 与系统名间距 8px，系统名 14px、`--color-text-1`。头部底色与应用最外层底色一致（`--color-fill-2`），靠底色而不是分隔线与内容区区分；内容区为白底时可改用 `--color-bg-2` + 底部 1px `--color-border-2`。头部尺寸不同时可按比例调整，但仍须遵守上面的硬约束。

## 二、浏览器页签图标（favicon）

页签图标可以按系统或产品需求单独设计；**没有特殊需求时使用默认的 `assets/brand/favicon.ico`**。

## 三、品牌主色

- 品牌主色即海信绿 `#00AAA6` = `--primary-6`。交互主色用 `primary-6`，hover 用 `primary-5`，active 用 `primary-7`（见 [design-core.md C9](design-core.md#c9-取值铁律)）。
- 主色承担**主操作、选中态、进度、关键焦点**这些需要被一眼识别的角色；页面的大面积底色用中性色分层（灰底 `--color-fill-2` + 白面板 `--color-bg-1`，见 [C3](design-core.md#c3-页面背景分层)），不用主色铺底。
- 同一组按钮只有一个主按钮（[C4](design-core.md#c4-按钮组规范)），主色才有足够的辨识度。
- 不使用其它蓝、绿近似色冒充主色，也不使用 Tailwind / 组件库默认主色。

## 四、字体

使用 `--font-family`（Inter 起头，中文依次回退到苹方、冬青黑体、Noto Sans、微软雅黑）。代码等宽内容用 `--code-family`。不引入其它品牌字体。

## 五、尚未定义（不要自行补充）

以下品牌要素当前没有正式规范，生成时不要自行发明统一风格，按产品需求就事论事，并在交付说明中标注「未按品牌规范，因规范暂缺」：

- 插画、空状态、引导图的风格
- 界面文案语气与用词规范
- 品牌动效 / 加载动画
