# MSC · 全球营销云中台 · 业务组件

## 触发条件

需求文本中出现以下任一字眼，即判定为 MSC 场景：

> **MSC** ／ **全球营销云中台** ／ **营销云中台** ／ **营销中台**

- 命中 → 下表场景**优先使用** MSC 业务组件。
- 未命中 → **不要使用**本目录的组件，改用 Pangea 通用组件。
- 只是顺带提了一句、或同时提到多个产品而无法判断 → **问用户确认**，不要自行推断。

## 组件清单

| 组件 | 覆盖场景 | 替代的通用组件 | 文档 |
|---|---|---|---|
| MSC 附件上传 `MscAttachmentUpload` | 表单中的**附件上传**：需要用详细表格呈现已上传附件，并支持预览 / 下载 / 删除 / 批量下载 | `a-upload`（原生上传的轻量文件列表） | [attachment-upload.md](attachment-upload.md) |

## 源码位置

脚手架 `templates/project-starter/src/components/msc/`。复制到目标工程时保留 `msc/` 子目录与 `Msc` 前缀，便于和通用组件区分。

## 使用要点（本产品通用）

- 业务组件**不改造成通用组件**：如果 MSC 之外的产品也需要类似能力，应在通用层另立组件或直接用 Pangea 通用组件，不要把 MSC 组件搬过去。
- 组件只负责**呈现 + 抛语义事件**，不实现真实接口。demo 用 mock，开发交付时由宿主页面接真实接口，组件本身不改。
- 生成需求文档时，若判定为 MSC 场景，请在「全局约定」里写明 `产品线：MSC（全球营销云中台）`，让后续每页的组件选型有据可依。
