## C1 表单承载容器决策路径

出现「新建 / 编辑」等表单场景时，判断该用**对话框 / 抽屉 / 表单页**中的哪一种。**先估完成时间，再看是否命中特定场景。**

### 第一步：预估完成时间

| 时间档 | 容器 | 用户心理模型 |
|---|---|---|
| **≤ 30 秒** | 对话框 | "快速处理一下，马上回来" |
| **30 秒 ~ 3 分钟** | 抽屉 | "需要花点时间填写，但我还在这个页面的语境里" |
| **> 3 分钟** | 表单页 | "这是一项独立的任务，我要集中精力完成" |

### 第二步：特定场景（命中则覆盖第一步结论）

| 条件 | 直接结论 | 原因 |
|---|---|---|
| 短步骤（2 步）且每步均为短字段 | → **对话框**（分步） | 总时长仍在 30s 内，对话框可承载 |
| 多步骤（≥ 3 步）或含分支逻辑 | → **抽屉 / 表单页** | 步骤导航 + 内容量需要完整页面 |
| 多个分组（≥ 3 组） | → **抽屉** | 内容量较大，需更大的竖向空间 |
| 多个分组（≥ 3 组）+ 锚点导航 | → **表单页** | 内容结构化程度高，且有左右布局情况，需独立空间 |
| 填写时必须持续参考页面数据 | → **抽屉（非模态）** | 对话框遮挡页面，无法参考 |

> 装不进对话框最大档位（1000px）的内容，说明它不该待在对话框里 → 升级到抽屉或表单页。

## C2 对话框宽度档位（硬约束）

对话框宽度**只有三个档位**，且**不允许超过 1000px**：

| 档位 | 用在什么场景 |
|---|---|
| **520px** | 默认档。字段少的轻量录入、单个选择 / 输入、简单信息展示 |
| **720px** | 字段较多需要 2 列栅格、或内容较长需要更多横向空间 |
| **1000px** | **仅当对话框内含表格等宽组件时**（只读子表、可编辑明细、宽数据列表） |

- 不得写 712 / 800 / 960 / 1200 这类非档位值；1000 档要能说出理由（里面没有表格就降档）。
- **确认类对话框固定 400px**：删除确认、操作确认、风险提示。这里的 400 是**含内边距的实际视觉宽度**（按 `box-sizing: border-box` 计）。
- 窄屏防溢出：宽度不能超过视口，窄屏改小宽度或全屏。

## C3 页面背景分层

- **应用最外层底色**：`--color-fill-2`（灰）。内容区域默认透明，漏出这层灰。
  - ⚠️ `--color-fill-*` 在暗色下是**半透明叠加色**（如 `rgba(255,255,255,0.08)`），单独铺会透出下面的白色画布。最外层要先铺不透明底再叠灰：`background-color: var(--color-bg-1); background-image: linear-gradient(var(--color-fill-2), var(--color-fill-2));`，或在它外面再包一层 `--color-bg-1`。
- **常规内容页**（列表、表单、详情——页面本身是一整块内容）：页面根元素设白底 `--color-bg-1` 铺满内容区，形成「白面板浮在灰底上」。
- **仪表板 / 工作台类聚合页**（多个独立区块拼合）：页面根保持透明（露出灰底），每个区块用**白底、无边框**卡片承载，靠底色差而非边框线区隔；卡片用 `--border-radius-large`（8px）+ 极轻阴影（如 `0 1px 4px rgba(0,0,0,0.05)`）。卡内强调图标可用「浅底色芯片」（强调色约 10% 透明度做底、同色图标）。
- 背景只用变量，不写死 hex。

## C4 按钮组规范

1. **按钮组在父级容器左侧时，按重要性从左至右排列**（最重要的在最左）。例：表格顶部操作栏。
2. **按钮组在父级容器右侧时，按重要性从右至左排列**（最重要的在最右）。例：页面顶部操作栏、对话框底部。
3. **一组超过 3 个按钮时**，视情况把次要按钮折叠进「更多」下拉菜单。
4. **同一组最多 1 个主按钮**，其余用次按钮 / 文本按钮。
5. **危险操作**（删除、作废）用 danger 状态，不设为默认焦点、不用主色。

> 1、2 的方向差异来自阅读起点：两者都是「最重要的离容器边缘最近」。

## C5 控件密度

中后台默认紧凑，但**密度按区域性质分档，不是全局一律最小**。控件高度只用 `--size-mini / small / default / large`（24 / 28 / 32 / 36px）。

| 区域 | 档位 |
|---|---|
| 浏览类页面（列表 / 卡片列表 / 左树右表）的**操作栏按钮、搜索控件、树内搜索框** | 紧凑档 `--size-small`（28px） |
| **表格行** | 中密度：单元格上下内边距 `--table-size-medium-padding-vertical`（7px）、左右 `--table-size-medium-padding-horizontal`（16px），字号 `--font-size-body-3`（14px） |
| **分页器** | 紧凑档（28px） |
| **表单页的表单控件与操作栏按钮** | 默认档 `--size-default`（32px）——表单字段是页面主体，不压缩 |
| 表格单元格内的**内联控件**（开关、文本按钮等） | 紧凑档或迷你档（28 / 24px） |

## C6 状态不只靠颜色传达

- **状态必须「颜色 + 文字」双通道**：状态列用「色点 + 状态文字」，不允许只给一个色点。
- 图表系列、多色标签 / 分类除颜色外要有图例文字或图标区分。
- **纯图标按钮必须有可访问名**（`aria-label` 或 tooltip 文本）。
- 正文对比度 **≥ 4.5:1**；亮暗两套都要满足。
- 焦点状态必须可见，不得用 `outline: none` 去掉而不补替代样式。

## C7 组件选型速查

| 组件 | 结论 |
|---|---|
| 表格 | 规整多列结构化数据用它；每条信息图文混合且丰富时改用卡片 |
| 卡片 | 内容分块、卡片网格、仪表板区块用它；**仅需分隔就用间距，别为分隔套卡片** |
| 表单 | 结构化字段录入 + 校验；校验时机统一（失焦或提交，同一表单不混用） |
| 对话框 | 轻量确认与不跳转的临时任务；长流程改表单页，侧向持久面板改抽屉。宽度见 C2，容器选择见 C1 |
| 选择器 | 有限选项单选 / 多选；**选项 2–3 个改单选组**，布尔改开关，层级数据改树选择 |
| 标签页 | 同一区域切换多组**成块内容**；页面级导航用菜单 / 路由，步骤流程用步骤条，工具栏内切换数据视图用分段控件（C8） |
| 菜单 | 侧边 / 顶部导航 |
| 徽标 / 状态点 | 状态点 + 文字、未读计数；分类标注改用标签。必须带文字（C6） |
| 警告提示 | 页内**持久**提示用它；操作后**瞬时**反馈用全局消息，需确认用确认对话框 / 气泡确认 |
| 分页 | 总数与真实数据联动不写死，筛选后回到第 1 页 |

## C8 行内视图切换用分段控件，且一律居左

页头 / 工具栏里切换**同一块内容的数据范围**（全部 / 待我审批 / 已处理这类平级视图）：

- 用**分段控件**（按钮样式的单选组），**不用标签页**。标签页的导航条会占满整行，并会渲染一块内容面板，放在工具栏里会撑出多余间距。
- **一律居左**，不居中、不右对齐。
- 分工：标签页切换后下方**整块内容替换**；分段控件切换后**结构不变、只换数据**。

## C9 取值铁律

- **颜色只用语义变量或调色板变量**，绝不硬编码 hex：
  - 语义色：`var(--color-text-1)`、`var(--color-bg-2)`、`var(--color-border-2)`、`var(--color-fill-2)` 等。
  - 品牌 / 状态 / 扩展色以 RGB 分量存储，需包 `rgb()`：`rgb(var(--primary-6))`、`rgba(var(--primary-6), 0.2)`、`rgb(var(--success-6))`。
- **品牌主色是青绿色 `#00aaa6`（`--primary-6`）**。交互主色用 `primary-6`，hover 用 `primary-5`，active 用 `primary-7`。
- 字号、间距、圆角、阴影、动效时长、层级只用对应变量档位（`--font-size-*`、`--spacing-*`、`--border-radius-*`、`--shadow*`、`--transition-*`、`--z-index-*`），不写 3 / 7 / 13px 这类非档值。
- 常用：正文 14px（`--font-size-body-3`）；按钮 / 输入框圆角 4px（`medium`），卡片 / 对话框 8px（`large`）。
- 只用语义变量即可自动适配暗色；不为暗色单独硬编码颜色。
- 数据可视化、多色分类等语义色不够用时，从扩展色板取（`rgb(var(--purple-6))`、`rgb(var(--cyan-6))` 等）。

## C10 响应式适配

每个页面都必须做响应式适配。中后台工作区常见 1280–1920，但内容区宽度会随侧边栏展开 / 折叠、分屏、小屏笔记本变化，也要兼容约 1024 的窄屏——不允许固定死宽导致字段挤压、内容溢出或非预期横向滚动。

- **多列表单随宽度收敛列数**：断点 xs<576 / sm≥576 / md≥768 / lg≥992 / xl≥1200 / xxl≥1600。3 列表单：窄屏 1 列 / ≥576 2 列 / ≥992 3 列；2 列表单：窄屏 1 列 / ≥576 2 列；整行字段（多行文本、子表单）始终占满一行。
- **卡片 / 磁贴网格自适应**：`grid-template-columns: repeat(auto-fill, minmax(<最小宽>, 1fr))`，不写死列数。
- **表格窄屏保可用**：横向滚动，或隐藏次要列、改卡片展示。
- **操作栏 / 筛选行允许换行**（`flex-wrap`），避免按钮组与搜索框互相挤压。
- **固定宽度设上限防溢出**：对话框、面板等宽度 ≤ 视口；侧栏、锚点等辅助区窄屏可隐藏或下移。
